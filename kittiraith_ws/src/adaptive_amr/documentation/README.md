# documentation/ — module documentation (adaptive_amr)

Per-module documentation lives in each package's own `README.md` (25-point
template: objective → theory → implementation → testing → debugging →
improvements → interview questions).

This folder aggregates:

- phase documents (see `docs/` at the workspace root),
- the final research-style report (Phase 10),
- architecture diagrams and the ROS graph.

Keep this folder in sync with each phase's commits.
